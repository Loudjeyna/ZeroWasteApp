## 🚀 خطوات الفتح في Android Studio 2026.2

### 1. فتح المشروع
1. شغّل **Android Studio 2026.2**
2. اختر: **File → Open**
3. اختر مجلد **`zerowaste`** (وليس `app`)
4. انتظر Gradle Sync أول مرة (1-3 دقائق، ينزّل ~200MB من المكتبات)

### 2. ضبط JDK لو لزم
**File → Settings → Build, Execution, Deployment → Build Tools → Gradle**
- تأكّد أن **Gradle JDK = 17** (أو embedded JDK 17)

### 3. تشغيل التطبيق
- اختر **Run → Run 'app'** أو `Shift+F10`
- يجب أن تظهر شاشة بها:
  - شريط سفلي بـ 5 تبويبات + زر أخضر دائري في الوسط (FAB)
  - 4 شاشات placeholder + شاشة إضافة كاملة

## ⚠️ مشاكل محتملة + حلولها

### 1) `Compose Compiler Plugin not found`
**الحل:** تأكّد من `app/build.gradle.kts` يحوي:
```kotlin
plugins {
    alias(libs.plugins.kotlin.compose)
}
```

### 2) `Hilt not configured`
**الحل:** تأكّد من:
- `settings.gradle.kts` يحوي `mavenCentral()` (موجود ✅)
- `app/build.gradle.kts` يحوي `alias(libs.plugins.hilt)` (موجود ✅)

### 3) `Cannot find string 'food_apple'`
**الحل:** تأكّد من أن `strings.xml` (موجود في `values/`) يحوي كل النصوص (موجود ✅).

### 4) خطوط لا تظهر (Cairo/Poppins)
**الحل:** يستعمل التطبيق Google Fonts Provider عبر GMS. على المحاكي بدون Google Play Services، قد تفشل.
**بديل:** استبدل محتوى `Type.kt` بهذا السطر للتشغيل السريع:
```kotlin
val CairoFontFamily = FontFamily.SansSerif
val PoppinsFontFamily = FontFamily.SansSerif
```

### 5) `Theme.ZeroWaste.SplashScreen not found`
**الحل:** تأكّد أن `themes.xml` يحوي `<style name="Theme.ZeroWaste.SplashScreen">` (موجود ✅).

### 6) أخطاء kapt مع Hilt
**الحل:** في `app/build.gradle.kts`، تأكّد أن:
```kotlin
plugins {
    alias(libs.plugins.kotlin.kapt)
    alias(libs.plugins.hilt)
}
```

### 7) أخطاء AGP مع AS 2026.2
إذا اقترح AS رفع AGP:
- إما ارفعه: عدّل `agp = "8.7.2"` في `libs.versions.toml` إلى `8.9.0` أو `8.10.0`
- أو اقبل التحديث المقترح (اضغط **Update**)
